# Walk with Christ ✝️

A highly optimized, fully responsive Catholic web application landing page built with modern frontend architecture.

## 🚀 Features

- **Daily Walk with God:** Asymmetrical grid header layout featuring custom navigation cards.
- **Featured Section:** Dual-card pattern forcing synchronized maximum heights, utilizing CSS `linear-gradient` text/image blending and a custom-engineered cross glyph divider.
- **Popular Prayers:** 6-column dynamic CSS Grid layout designed to protect text alignment on viewports down to mobile screens.
- **Resources & Blog:** A split-container system handling both vertical image-top article flows and horizontal media-left miniature blocks seamlessly.
- **Newsletter Subscription:** Dark-themed action banner utilizing native, hardware-accelerated CSS filters (`filter: invert()`) to dynamically convert asset coloration without extra image requests.

## 🛠️ Tech Stack

- **Structure:** Semantic HTML5 
- **Layout:** CSS Grid Architecture & Flexbox Alignment
- **Styling:** CSS3 Custom Properties (Design System Variables)
- **Typography:** Google Fonts Integration (`Playfair Display`, `Segoe UI`)

## 📁 Project Structure

- `index.html` — Semantic main webpage structure.
- `css/styles.css` — Core stylesheet, design variables, and media queries for responsiveness.
- `assets/` — Local directory containing optimized images and SVG iconography.
